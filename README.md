# Daily Tasks

A simple daily task tracker that installs on your iPhone's home screen.

## Put it on GitHub

1. Sign in at github.com and create a new repository (for example `daily-tasks`). Set it to Public.
2. Click "uploading an existing file" on the new repo page and drag in ALL the files from this folder:
   index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png, icon-512.png.
   Click "Commit changes".
3. Open Settings > Pages. Under "Build and deployment", set Source to "Deploy from a branch",
   pick the `main` branch and the `/ (root)` folder, then Save.
4. Wait a minute or two. The page shows your link: https://YOUR-USERNAME.github.io/daily-tasks/

## Add it to your iPhone

1. Open that link in Safari (it has to be Safari).
2. Tap the Share button, then "Add to Home Screen", then Add.
3. Open it from the new home screen icon.

## Good to know

- Tasks are saved on the phone, inside the home screen app. Add your tasks after installing it,
  because the Safari tab and the home screen app keep separate data.
- Nothing syncs between devices, and deleting the app deletes its tasks.
- To update the app later, upload the changed files to the repo again.
